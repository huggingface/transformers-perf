Pull requests

Each PR runs side by side against the commit it is based on (for a merged PR, main right before the merge). Verdicts are from its latest run.

Series

Latest main every day at 03:00 UTC, 3 runs. The line is the median of the runs' medians; the band spans the runs' medians (min–max). Generation: harness on one GPU. Multimodal processors: tperf.processors.bench turns a fixed batch of images, videos or audio into model inputs on 8 pinned CPU cores, 5 timed calls per run. Multimodal encoders: the model's vision or audio encoder on those inputs (GPU, bf16), with its GPU→CPU syncs per call: each one stalls the CPU until the GPU catches up, which in a serving engine breaks the overlap of the encoder with the rest of the step.

Only what runs every day is shown: a scenario that failed, or a metric that was not recorded, in any of the last 7 daily runs is left out until it has a clean week.

Side-by-side runs

Both sides run at the same time on two GPUs that swap every round; change is the PR's effect with the GPU difference fitted out, with a 95% CI over rounds. Positive = the PR is worse (slower, or less throughput). Verdict threshold: 1%.
